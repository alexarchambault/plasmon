```scala
type String
```

***

The `String` type in Scala has methods that come either from the underlying
 Java String (see the documentation corresponding to your Java version, for
 example [http://docs.oracle.com/javase/8/docs/api/java/lang/String.html](http://docs.oracle.com/javase/8/docs/api/java/lang/String.html)) or
 are added implicitly through [scala.collection.immutable.StringOps](scala.collection.immutable.StringOps).
